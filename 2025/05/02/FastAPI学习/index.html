Restful API 设计指南

常见方法如下

GET：从服务器读取资源（查询资源）。
POST：在服务器创建资源（通常用于添加新资源）。
PUT：在服务器更新资源（通常用于替换或更新现有资源）。
DELETE：从服务器删除资源。
PATCH：部分更新资源。

Query 是 FastAPI 提供的“查询参数声明器”，从 fastapi import Query 引入 它不是 Python 关键字，而是一个构造函数（返回 fastapi.params.Query 实例），用在函数参数的默认值位置来描述该参数的来源、默认值、校验规则和文档信息
